價值主張與定位 Value Proposition & Positioning

選好目標市場之後，要讓那群人記住「為什麼選你而不是別人」——這就是定位，STP 的最後一步。

本章重點

  • 定位 = 在目標顧客心中佔據一個獨特、有價值的位置。
  • 價值主張：顧客選你能得到的整體利益。
  • 定位三要素：參考架構、共同點（POP）、差異點（POD）。
  • 一句定位陳述要寫出：對誰、屬於哪一類、有什麼不同、為什麼可信。

價值主張

價值主張（value proposition）是公司承諾帶給顧客的整體利益組合，回答的是「顧客為什麼要買我的？」。顧客感受到的價值 = 得到的利益 − 付出的成本（金錢、時間、心力）。

參考架構

參考架構（frame of reference）告訴顧客「我是哪一類的產品、跟誰比」。先決定和誰競爭，才知道要強調哪些相同點與不同點。

例子

同一瓶氣泡水，放在「汽水」類別裡可以強調「無糖」，放在「礦泉水」類別裡則強調「更有口感」。參考架構不同，差異點就不同。

共同點與差異點

共同點 POP差異點 POD
英文Points of ParityPoints of Difference
作用證明「我也有」，讓顧客把你當成合格選項證明「只有我有」，給顧客選你的理由
要求做到「夠好」就好，不必最強要讓顧客在意、相信、且對手難模仿

沒有 POP，顧客根本不會考慮你；沒有 POD，顧客沒理由選你。兩者缺一不可。

定位陳述怎麼寫

常見格式：

格式

對於〔目標市場〕，〔品牌〕是〔參考架構／類別〕中，能〔差異點〕的品牌，因為〔可信的理由〕。

好的定位要簡單、可信、和對手不同，而且公司真的做得到。

名詞卡

定位 Positioning
設計產品與形象，在目標顧客心中佔據獨特位置。
價值主張 Value proposition
公司承諾給顧客的整體利益組合。
參考架構 Frame of reference
決定品牌屬於哪個類別、和誰競爭。
差異點 POD
顧客在意、相信，且對手難以做到的獨特屬性或利益。

考試提醒

  • POP 是「讓自己有資格被考慮」，POD 是「被選擇的理由」，題目常把兩者描述對調。
  • 定位的順序在 STP 最後：先區隔、再選目標、最後定位。
  • POD 的條件：desirable（顧客想要）、deliverable（公司做得到）、differentiating（和對手不同）。

自我測驗

  1. Attributes that a brand shares with competitors so that it is considered a legitimate option are called:

    1. Points of difference
    2. Points of parity
    3. Value propositions
    4. Frames of reference
    看答案

    答案：B。和對手共有、證明「我也合格」的屬性是 POP。

  2. In the STP process, positioning comes:

    1. Before segmentation
    2. Between segmentation and targeting
    3. After targeting
    4. At the same time as segmentation
    看答案

    答案：C。順序是 Segmentation → Targeting → Positioning。

  3. Deciding which product category a brand competes in is part of establishing its:

    1. Frame of reference
    2. Marketing mix
    3. Brand equity
    4. Segmentation base
    看答案

    答案：A。決定類別與競爭對象 = 參考架構。
