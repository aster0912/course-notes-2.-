# 課程複習講義站

自己考前複習用的管院課程重點整理。考試是全英文選擇題、投影片重點不明顯，所以把每章濃縮成中文重點，難的術語附英文、容易混淆的觀念另外比較，最後用英文選擇題自我測驗。

- 純靜態網站（HTML + CSS + 少量 JS），部署在 GitHub Pages
- 目前收錄：行銷管理 Ch 1、6、7、12
- AI 協作規則：見 [`CLAUDE.md`](CLAUDE.md)（`AGENTS.md` 內容相同）

## 新增一篇講義

1. 複製 `templates/lesson-template.html` 到 `lessons/<科目>/chNN-<slug>.html`
2. 依模板填入六個固定區塊
3. 在 `assets/lessons.js` 登記
4. 首頁自動出現

詳細規則見 `CLAUDE.md`。
